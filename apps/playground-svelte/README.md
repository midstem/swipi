# @swipi/playground-svelte

A local playground environment for testing the Swipi Svelte adapter.

## Getting Started

To run the playground locally, you can use either of the following commands from the root of the monorepo:

```bash
npm run start --workspace @swipi/playground-svelte
```

Or, if you are inside the `apps/playground-svelte` directory:

```bash
npm run start
```
