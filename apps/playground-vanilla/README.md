# @swipi/playground-vanilla

A local playground environment for testing the Swipi engine — `createSwipi`
with no framework around it.

## Getting Started

To run the playground locally, you can use either of the following commands from the root of the monorepo:

```bash
npm run start --workspace @swipi/playground-vanilla
```

Or, if you are inside the `apps/playground-vanilla` directory:

```bash
npm run start
```
